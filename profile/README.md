## Senior engineers, AI-accelerated delivery

Lyvek is a software agency of senior engineers who use AI to deliver faster, and keep the
judgment where it belongs. Seniors specify, direct and verify; the tooling accelerates.

**What we build:** SaaS platforms and multi-tenant applications · API design and integrations ·
AI-powered features, such as assistants and search over a client's own knowledge · maintenance,
optimization and consulting.

**How we work:**

- Important decisions are written down, with their reasons, while the alternatives are still visible.
- The API contract is agreed before code, so work runs in parallel, and tests come first.
- No change merges until an engineer approves it.
- Clients see working software every week, in a repository they can access from day one; the code we write for them, and their data, are theirs.

Houston, TX · Medellín, Colombia — two countries, one team, in English and Spanish.

## Ingenieros senior, entrega acelerada con IA

Lyvek es una empresa de software formada por ingenieros senior que usan IA para entregar más
rápido, sin delegar el criterio. Las personas especifican, dirigen y verifican; las herramientas
aceleran.

**Qué construimos:** plataformas SaaS y aplicaciones multi-tenant · diseño e integración de APIs ·
funciones con IA, como asistentes y búsqueda sobre el conocimiento propio del cliente ·
mantenimiento, optimización y consultoría.

**Cómo trabajamos:**

- Dejamos por escrito las decisiones importantes y sus razones mientras las alternativas siguen a la vista.
- Acordamos el contrato de la API antes del código, de modo que el trabajo avanza en paralelo, y las pruebas se escriben primero.
- Ningún cambio se integra sin la aprobación de un ingeniero.
- El cliente ve software funcionando cada semana, en un repositorio al que tiene acceso desde el primer día; el código que escribimos para él y sus datos son suyos.

Houston, TX · Medellín, Colombia — dos países, un equipo, en español y en inglés.
